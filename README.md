# Internship Skill-Gap Analytics System

📌 Project Overview

The Internship Skill-Gap Analytics System is a data analytics project designed to analyze students' technical skills and compare them with the skills required for internship and job roles.

The system helps identify Skill Match Percentage, Missing Skills, and Internship Readiness using data analysis and visualization.

🎯 Objectives

- Analyze student technical skills.
- Compare student skills with required internship skills.
- Calculate Skill Match Percentage.
- Identify missing or required skills.
- Analyze internship readiness.
- Present insights through an interactive Power BI dashboard.

🛠️ Technologies Used

- Python
- Pandas
- CSV
- Power BI
- Microsoft Excel
